# 英语单词学习游戏 MVP

纯前端自用版，使用 HTML、CSS、JavaScript、Web Speech API 和 localStorage。

## 目录结构

- `index.html`：应用入口。
- `styles/main.css`：页面样式。
- `src/data.js`：加载词库和学习计划。
- `src/storage.js`：localStorage 进度保存。
- `src/speech.js`：朗读、语音识别和朗读完成度计算。
- `src/app.js`：学习流程、游戏模块、报告和词库预览。
- `data/`：词库和学习计划 JSON。
- `CODEX_HANDOFF.md`：产品交接说明。

## 运行方式

因为浏览器直接打开本地 HTML 时不能稳定 `fetch` JSON，请用本地静态服务运行：

```bash
cd /Users/ripflowers/Documents/enstudy
python3 -m http.server 4173
```

然后打开：

```text
http://127.0.0.1:4173/
```

推荐使用 Chrome 或 Edge。朗读使用 `SpeechSynthesis`；跟读识别使用 `SpeechRecognition`，浏览器不支持时会降级为自评完成。

## MVP 功能

- 学习者选择：一年级启蒙、初一考纲。
- 今日任务：按学习计划读取第 N 天单词。
- 单词卡片：单词、中文、分类、难度/拼写风险、3 条可点击朗读例句。
- 星空打陨石：听音选英文，包含得分、连击、护盾和句子播放。
- 发音打靶：单词跟读和句子跟读，按识别相似度给 1-10 环；包含麦克风波纹和命中动画，不可用时自评。
- 句子小火车：从多例句中抽题，听整句、补目标词、再读整句，正确后车厢动态通过。
- 听写工厂：听音输入拼写，默认只给单词长度；错误后逐步给少量提示；正确后字母装箱。
- Boss 战：混合听单词、听句子、选正确例句、拼写、选择、例句填空；初一增加首字母和词形变化；包含 Boss 血条、攻击和反击效果。
- 错词复仇：优先刷当天错词；如果当天还没有错词，则刷今日高拼写风险词，混合听音、例句选择、听写和填空。
- 今日报告：完成词数、正确率、朗读平均环数、游戏得分、最高连击、星级、错词和明日建议。
- localStorage 保存学习进度。
- 全部词库预览：搜索、分类筛选、学习者筛选、朗读。
- 动效和音效均为本地 CSS / Web Audio 实现，不使用后端或付费 API。

## 继续优化规划

短期优先级：

1. 例句质量：继续按类别补更多自然句型，尤其是初一词汇的短语搭配、词形变化和易混词句子。
2. 游戏目标：每关增加更明确的 1 分钟挑战、三连击奖励、无伤通关奖励。
3. 错词循环：错词复仇通关后，把仍然答错的词自动放进明日复习建议。
4. 句子玩法：加入“听句子选中文意思”“句子排序”“首字母句子填空”。
5. 视觉升级：星空关后续可升级为 Canvas 轨道下落，Boss 战可增加阶段形态。

## 测试说明

1. 打开首页，确认状态显示已加载 2000 个词条。
2. 切换“一年级启蒙”和“初一考纲”，确认今日词数分别为 10 和 15。
3. 进入今日任务，点击单词卡片的多个例句，确认每条都能朗读。
4. 进入“星空打陨石”，点击播放、播放句子和选项，确认得分、连击、护盾、下落和命中动画变化。
5. 进入“发音打靶”，分别测试单词跟读和句子跟读；如果浏览器不支持识别，确认可用自评继续，并观察靶心动画。
6. 进入“句子小火车”，听整句后填写目标词，确认正确后会朗读整句并触发车厢动画。
7. 进入“听写工厂”，确认默认只显示字母长度；第一次错误不显示字母提示，第二次后才给少量提示；正确后字母格装箱。
8. 完成 Boss 战，确认包含“选正确例句”题，Boss 血条扣减、攻击/反击动画和通关星级正常。
9. 进入“错词复仇”，如果已有错词确认优先刷错词；没有错词时确认会刷高风险词。
10. 打开“全部词库”，搜索 `about` 或中文分类，确认列表可筛选和朗读。
11. 刷新页面，确认今日结果仍保留；点击“重置今日”可清空当天记录。
